# PersonaStack Connector v0.1.9

## Changes

- Pairing a new external persona now replaces the previous local Connector binding on the same machine.
- Old local binding secrets are removed only after the replacement binding state is written successfully.
- Pairing output now clearly reports whether the local Connector link is active or replaced.
- Release packaging now targets the V1 macOS and Linux matrix only.

## Supported OS/arch

- macOS amd64 and arm64 archives.
- Linux amd64 and arm64 archives, `.deb`, and `.rpm` packages.

## Runtime caveats

- One machine can keep one active Connector link at a time.
- Pairing a different persona on the same machine replaces the prior local link.
- Full wakeable status still requires authenticated bridge connectivity, local runtime health, native MCP verification, and wake probe success.
- Native Windows packages are not part of the V1 release matrix.

## Upgrade

Download the archive or package for your platform from the GitHub Release assets and replace the previous `personastack-connector` binary. Re-run the pairing command for the external persona that should own this machine.

## Rollback

Reactivate the previous known-good Connector semver in the PersonaStack admin release metadata, then reinstall and re-pair that version on affected hosts if needed.
