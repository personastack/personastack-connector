# PersonaStack Connector v0.4.4

## Supported OS/arch

- macOS archive: `darwin/amd64`, `darwin/arm64`
- Linux archive: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `linux/amd64`, `linux/arm64`

## Runtime caveats

- System service scope is macOS-only and supports OpenClaw hosts.
- Hermes continues to use the default user LaunchAgent scope.
- The local runtime must be reachable and authenticated before PersonaStack can dispatch work.
- If a daemon kept stale local active-run state from a prior completed run, this release clears that stale local assignment when the API admits and dispatches a new run.

## Upgrade

- Install the new package or archive, then restart the Connector service.
- Existing bindings and PersonaStack MCP credentials are preserved.
- Re-pairing is not required for already linked ClawTop or M1 Hermes hosts.

## Rollback

- Reactivate v0.4.3 in the PersonaStack Connector release metadata.
- Reinstall v0.4.3 from the GitHub release assets if a host has already upgraded.
- Restart the Connector service after reinstalling the older binary.
