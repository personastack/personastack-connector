# PersonaStack Connector v0.3.2

## Supported OS/arch

- macOS amd64
- macOS arm64
- Linux amd64
- Linux arm64

## Runtime caveats

- OpenClaw Gateway must expose `agent.wait`.
- Long-running OpenClaw turns may exceed one Gateway wait window; Connector now keeps polling instead of treating that wait-window timeout as a failed run.
- PersonaStack MCP setup can still report degraded when the native runtime has not accepted the Connector stdio MCP config.

## Upgrade

Install or update through the PersonaStack external persona setup command after this version is activated as recommended.

## Rollback

Reinstall v0.3.1 from the GitHub release assets if OpenClaw wait polling regresses.
