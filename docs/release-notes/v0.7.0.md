# PersonaStack Connector v0.7.0

Adds macOS menu bar status, connector-owned update execution, and richer
non-secret status metadata for API and browser surfaces. This release keeps
Linux headless support and adds API-driven update guidance for Homebrew, `.deb`,
and `.rpm` installs.

## Supported OS/arch

- macOS: `darwin/amd64`, `darwin/arm64`
- Linux archives: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `amd64` and `arm64`

## Runtime caveats

- macOS menu bar status is shown only for user-scope LaunchAgent or foreground
  runs. macOS system LaunchDaemon runs remain headless.
- Linux runs remain CLI-first and headless. Linux update guidance is selected
  from the Connector-reported OS, architecture, install channel, and privilege
  state.
- One-click updates execute only Connector-owned finite update procedures. The
  Connector never executes arbitrary shell commands from API metadata.
- Local binding, bridge, MCP, and runtime secrets remain in OS credential
  storage.
- No native Windows artifact is included in this release.

## Upgrade

- Upgrade through Homebrew on macOS or the published Linux archive/package for
  your OS and architecture.
- User-scope macOS Homebrew installs may update through the new menu action or
  browser update action after the API marks this version recommended.
- Linux `.deb` and `.rpm` installs can copy the exact package-manager command
  shown by PersonaStack. One-click Linux update appears only when the Connector
  already has the needed package-manager privilege.
- Re-pairing is not required for existing pairings.

## Rollback

- Activate the previous recommended Connector semver in PersonaStack API
  release metadata.
- Reinstall the previous Homebrew, archive, `.deb`, or `.rpm` artifact.
- Restart the Connector service after rollback.
