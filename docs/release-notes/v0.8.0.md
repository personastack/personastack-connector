# PersonaStack Connector v0.8.0

Reports locally verified Connector installation metadata to PersonaStack. Product
surfaces can now distinguish Homebrew, Debian, and RPM installations without
guessing an update command or exposing local paths.

## Supported OS/arch

- macOS: `darwin/amd64`, `darwin/arm64`
- Linux archives: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `amd64` and `arm64`

## Runtime caveats

- The Connector reports only locally verified installation metadata.
- Homebrew, `.deb`, and `.rpm` installations remain manual updates.
- Archive and unrecognized installations do not offer an update command.
- Connector bridge sessions continue to use outbound-only websocket transport.
- No native Windows artifact is included in this release.

## Upgrade

- Upgrade through Homebrew on macOS or the published Linux archive/package for
  your OS and architecture.
- Restart the Connector service after replacing the binary.
- Re-pairing is not required.

## Rollback

- Reinstall v0.7.6 from the GitHub release assets or Homebrew formula history.
- Restart the Connector service after rollback.
