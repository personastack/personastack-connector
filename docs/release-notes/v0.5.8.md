# PersonaStack Connector v0.5.8

Fixes Hermes Agent hosts whose API-server toolsets explicitly disabled MCP
tools even though PersonaStack MCP was configured.

## Supported OS/arch

- macOS: `darwin/amd64`, `darwin/arm64`
- Linux archives: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `amd64` and `arm64`

## Runtime caveats

- Hermes repair removes `no_mcp` from `platform_toolsets.api_server` so
  PersonaStack MCP tools are visible in externally dispatched Hermes runs.
- Hermes MCP verification now requires the configured PersonaStack MCP server to
  appear in the Hermes API-server tool registry.
- OpenClaw native MCP behavior is unchanged.

## Upgrade

- Upgrade through Homebrew on macOS or the published Linux archive/package for
  your OS and architecture.
- Run `personastack-connector mcp repair` or restart the Connector service after
  replacing the binary.

## Rollback

- Reinstall v0.5.7 from the GitHub release assets or Homebrew formula history.
- Restart the Connector service after rollback.
