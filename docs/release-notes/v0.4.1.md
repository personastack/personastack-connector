# PersonaStack Connector v0.4.1

## Supported OS/arch

- macOS archive: `darwin/amd64`, `darwin/arm64`
- Linux archive: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `linux/amd64`, `linux/arm64`

## Runtime caveats

- System service scope is macOS-only and supports OpenClaw hosts in this release.
- Hermes continues to use the default user LaunchAgent scope.
- A system LaunchDaemon keeps Connector running before user login but does not prevent machine sleep.
- The local runtime must still be reachable and authenticated after wake before PersonaStack can dispatch work.

## Upgrade

- Install the new package or archive, then run the normal pairing command.
- Use `--service-scope system` only for macOS OpenClaw machines that should reconnect before user login.
- Existing user-scope installs continue to run as LaunchAgents.

## Rollback

- Reactivate v0.3.6 in the PersonaStack Connector release metadata.
- Reinstall v0.3.6 from the GitHub release assets if a host has already upgraded.
- Re-pair affected hosts if local state was intentionally moved between user and system scopes.
