# PersonaStack Connector v0.5.11

Hardens Connector runtime sessions so local daemon retries and native runtime
streams recover more predictably across gateway drains, transient websocket
failures, and OpenClaw stream interruptions.

## Supported OS/arch

- macOS: `darwin/amd64`, `darwin/arm64`
- Linux archives: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `amd64` and `arm64`

## Runtime caveats

- Connector bridge sessions continue to use outbound-only websocket transport.
- Local binding and runtime secrets remain in OS credential storage.
- OpenClaw streaming remains bounded by the configured native runtime behavior.
- No native Windows artifact is included in this release.

## Upgrade

- Upgrade through Homebrew on macOS or the published Linux archive/package for
  your OS and architecture.
- Restart the Connector service after replacing the binary.
- Run `personastack-connector status --repair` if the local runtime reports stale
  MCP or bridge configuration after upgrade.

## Rollback

- Reinstall v0.5.10 from the GitHub release assets or Homebrew formula history.
- Restart the Connector service after rollback.
