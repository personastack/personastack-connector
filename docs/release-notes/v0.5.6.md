# PersonaStack Connector v0.5.6

## Supported OS/arch

- macOS archive: `darwin/amd64`, `darwin/arm64`
- Linux archive: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `linux/amd64`, `linux/arm64`

## Runtime caveats

- Connector protocol v2 is required by the live PersonaStack API.
- Hermes and OpenClaw hosts should keep the Connector service pointed at the installed package binary.
- Local runtime credentials and bridge secrets remain host-local.

## Upgrade

- Install the new package or archive, then restart the Connector service.
- Existing bindings and PersonaStack MCP credentials are preserved when the host can read its local secret store.
- Re-pair if the previous package was v0.5.1 and the API reports `unsupported_connector_version`.

## Rollback

- Reactivate v0.5.0 or another known-good semver in the PersonaStack Connector release metadata.
- Reinstall the previous semver from GitHub release assets or the Homebrew tap after moving the tap back.
- Restart the Connector service after reinstalling the older binary.
