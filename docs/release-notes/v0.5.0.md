# PersonaStack Connector v0.5.0

## Supported OS/arch

- macOS archive: `darwin/amd64`, `darwin/arm64`
- Linux archive: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `linux/amd64`, `linux/arm64`

## Runtime caveats

- The Connector keeps one active gateway websocket session per binding.
- `server.draining` closes the current session and reconnects with a fresh generation instead of overlapping sessions.
- Stale websocket generations cannot update local runtime state, cancel native runs, or emit stale terminal frames.
- Capability reports preserve live wakeability after a successful current-session wake probe.

## Upgrade

- Install the new package or archive, then restart the Connector service.
- Existing bindings and PersonaStack MCP credentials are preserved.
- Re-pairing is not required for already linked Hermes or OpenClaw hosts.

## Rollback

- Reactivate v0.4.6 in the PersonaStack Connector release metadata.
- Reinstall v0.4.6 from the GitHub release assets if a host has already upgraded.
- Restart the Connector service after reinstalling the older binary.
