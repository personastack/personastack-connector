# PersonaStack Connector v0.3.1

## Supported OS/arch

- macOS amd64 and arm64 archives.
- Linux amd64 and arm64 archives, `.deb`, and `.rpm` packages.

## Runtime caveats

- Hermes and OpenClaw runtime support still requires the local runtime to be installed and reachable on the Connector host.
- Auto-detected OpenClaw credentials are used only with loopback Gateway URLs.
- Forced fallback secret storage now bypasses macOS keychain reads and writes while still best-effort clearing stale keychain entries.
- Linux keeps keyring-first upgrade compatibility and continues to use the owner-only encrypted fallback store when the keyring is unavailable.

## Upgrade

- Reinstall or upgrade Connector through the setup command shown in PersonaStack.
- Re-run the pairing command if the external persona needs to refresh its local binding.

## Rollback

- Activate the previous known-good Connector semver in PersonaStack admin release metadata.
- Reinstall that Connector version on affected hosts and re-run pairing if needed.
