# PersonaStack Connector v0.5.1

## Supported OS/arch

- macOS archive: `darwin/amd64`, `darwin/arm64`
- Linux archive: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `linux/amd64`, `linux/arm64`

## Runtime caveats

- OpenClaw Gateway `agent.params` must stay within the current Gateway schema.
- The Connector still uses PersonaStack assignment ids as OpenClaw idempotency keys and native run ids.
- Hermes behavior is unchanged from v0.5.0.

## Upgrade

- Install the new package or archive, then restart the Connector service.
- Existing bindings and PersonaStack MCP credentials are preserved.
- Re-pairing is not required for already linked Hermes or OpenClaw hosts.

## Rollback

- Reactivate v0.5.0 in the PersonaStack Connector release metadata.
- Reinstall v0.5.0 from the GitHub release assets if a host has already upgraded.
- Restart the Connector service after reinstalling the older binary.
