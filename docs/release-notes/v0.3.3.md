# PersonaStack Connector v0.3.3

## Supported OS/arch

- macOS amd64
- macOS arm64
- Linux amd64
- Linux arm64

## Runtime caveats

- Hermes run-event streaming may still fall back to status polling when the local runtime does not support stable event streams.
- Active run state is retained until PersonaStack acknowledges the terminal run event, which avoids losing run recovery state across connector reconnects.
- PersonaStack MCP setup can still report degraded when the native runtime has not accepted the Connector stdio MCP config.

## Upgrade

Install or update through the PersonaStack external persona setup command after this version is activated as recommended.

## Rollback

Reinstall v0.3.2 from the GitHub release assets if terminal acknowledgement or Hermes event fallback behavior regresses.
