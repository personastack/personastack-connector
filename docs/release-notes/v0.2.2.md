# PersonaStack Connector v0.2.2

## Supported OS/arch

- macOS amd64 and arm64 archives.
- Linux amd64 and arm64 archives, `.deb`, and `.rpm` packages.

## Runtime caveats

- Hermes and OpenClaw runtime support still requires the local runtime to be installed, authenticated, and reachable on the Connector host.
- Hostname reporting is non-secret operator metadata used by PersonaStack to label connected external personas.

## Upgrade

- Reinstall or upgrade Connector through the setup command shown in PersonaStack.
- Re-run the pairing command if the external persona needs to refresh its local binding.

## Rollback

- Activate the previous known-good Connector semver in PersonaStack admin release metadata.
- Reinstall that Connector version on affected hosts and re-run pairing if needed.
