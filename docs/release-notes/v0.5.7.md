# PersonaStack Connector v0.5.7

Fixes OpenClaw native capability reporting on hosts where Gateway
`skills.status` is unavailable but `tools.catalog` is available.

## Supported OS/arch

- macOS: `darwin/amd64`, `darwin/arm64`
- Linux archives: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `amd64` and `arm64`

## Runtime caveats

- OpenClaw capability discovery still prefers `skills.status` when available.
- OpenClaw hosts that do not expose `skills.status` now report prompt-safe
  `tools.catalog` tool-group summaries with the `openclaw_tools_catalog` source.
- If OpenClaw has not loaded the configured PersonaStack MCP server into its
  effective catalog, restart or repair the native runtime after upgrading.
- Hermes native capability reporting is unchanged.

## Upgrade

- Upgrade through Homebrew on macOS or the published Linux archive/package for
  your OS and architecture.
- Restart the Connector service after replacing the binary.

## Rollback

- Reinstall v0.5.6 from the GitHub release assets or Homebrew formula history.
- Restart the Connector service after rollback.
