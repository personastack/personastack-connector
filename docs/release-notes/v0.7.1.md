# PersonaStack Connector v0.7.1

Replaces the failed `v0.7.0` release attempt. It keeps the same Connector
features and fixes release packaging so macOS menu bar builds use native CGO
while Linux builds remain headless and CGO-free.

## Supported OS/arch

- macOS: `darwin/amd64`, `darwin/arm64`
- Linux archives: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `amd64` and `arm64`

## Changes

- Adds macOS menu bar status for user-scope LaunchAgent and foreground runs.
- Adds connector-owned update execution for finite API-reported update plans.
- Adds richer non-secret status metadata for API and browser surfaces.
- Keeps Linux CLI-first and headless while showing OS-specific update guidance.
- Splits release builds so macOS uses native systray CGO builds and Linux stays
  CGO-disabled.

## Runtime caveats

- macOS system LaunchDaemon runs remain headless.
- Linux update guidance is selected from the Connector-reported OS,
  architecture, install channel, and privilege state.
- One-click updates execute only Connector-owned finite update procedures.
- Local binding, bridge, MCP, and runtime secrets remain in OS credential
  storage.
- No native Windows artifact is included in this release.

## Upgrade

- Upgrade through Homebrew on macOS or the published Linux archive/package for
  your OS and architecture.
- User-scope macOS Homebrew installs may update through the new menu action or
  browser update action after the API marks this version recommended.
- Linux `.deb` and `.rpm` installs can copy the exact package-manager command
  shown by PersonaStack.
- Re-pairing is not required for existing pairings.

## Rollback

- Activate the previous recommended Connector semver in PersonaStack API
  release metadata.
- Reinstall the previous Homebrew, archive, `.deb`, or `.rpm` artifact.
- Restart the Connector service after rollback.
