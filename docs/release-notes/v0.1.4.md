# PersonaStack Connector v0.1.4

## Changes

- Keep release policy validation compatible with GitHub Actions environments where repository rulesets are not exposed to the workflow token.
- Preserve the required release environment reviewer gate before publishing artifacts or API release metadata.

## Supported OS/arch

- macOS amd64 and arm64 archives.
- Linux amd64 and arm64 archives, `.deb`, and `.rpm` packages.
- Windows amd64 archive.

## Runtime caveats

- Windows Authenticode signing is applied only when the release workflow has the Windows signing certificate configured.
- Windows archives are protected by the release checksums and sigstore release-manifest bundles when Authenticode signing is unavailable.

## Upgrade

Download the archive or package for your platform from the GitHub Release assets and replace the previous `personastack-connector` binary.

## Rollback

Reactivate the previous known-good Connector semver in the PersonaStack admin release metadata.
