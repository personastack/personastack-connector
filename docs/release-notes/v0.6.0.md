# PersonaStack Connector v0.6.0

Updates the external-agent bridge protocol to v3 so Connector callbacks carry
the active connection generation on every API-facing frame. This pairs with the
live API and Agent Gateway deadline-owned run expiry release.

## Supported OS/arch

- macOS: `darwin/amd64`, `darwin/arm64`
- Linux archives: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `amd64` and `arm64`

## Runtime caveats

- Connector bridge sessions continue to use outbound-only websocket transport.
- External-agent bridge protocol v3 is required by the matching live API and
  Agent Gateway release.
- Local binding and runtime secrets remain in OS credential storage.
- No native Windows artifact is included in this release.

## Upgrade

- Upgrade through Homebrew on macOS or the published Linux archive/package for
  your OS and architecture.
- Restart the Connector service after replacing the binary.
- Re-pairing is not required for existing pairings.

## Rollback

- Roll back API and Agent Gateway compatibility before reinstalling v0.5.12,
  because v0.5.12 emits protocol v2 bridge frames.
- Restart the Connector service after rollback.
