# PersonaStack Connector v0.5.12

Fixes bridge credential loading so stale local Keychain entries cannot override
the current paired binding secret when their private key no longer matches the
binding public key.

## Supported OS/arch

- macOS: `darwin/amd64`, `darwin/arm64`
- Linux archives: `linux/amd64`, `linux/arm64`
- Linux packages: `.deb` and `.rpm` for `amd64` and `arm64`

## Runtime caveats

- Connector bridge sessions continue to use outbound-only websocket transport.
- Local binding and runtime secrets remain in OS credential storage.
- Existing pairings without a stored bridge public key keep accepting their
  stored non-empty bridge private key.
- No native Windows artifact is included in this release.

## Upgrade

- Upgrade through Homebrew on macOS or the published Linux archive/package for
  your OS and architecture.
- Restart the Connector service after replacing the binary.
- Re-pair only if the local credential store already contains a mismatched
  bridge private key and the Connector still cannot connect.

## Rollback

- Reinstall v0.5.11 from the GitHub release assets or Homebrew formula history.
- Restart the Connector service after rollback.
