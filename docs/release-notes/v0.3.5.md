# PersonaStack Connector v0.3.5

## Supported OS/arch

- macOS amd64
- macOS arm64
- Linux amd64
- Linux arm64

## Runtime caveats

- Hermes run-event streaming may still fall back to status polling when the local runtime does not support stable event streams.
- Native MCP verification still depends on the runtime accepting the Connector stdio MCP config.
- macOS keychain access can be unavailable in SSH or headless sessions; Connector now falls back to its owner-only encrypted local secret store for binding secrets.

## Upgrade

Install or update through the PersonaStack external persona setup command after this version is activated as recommended.

## Rollback

Reinstall v0.3.4 from the GitHub release assets if fallback secret storage or Hermes setup behavior regresses.
