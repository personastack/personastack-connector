# Security

Report security issues privately to security@personastack.ai.

Supported versions are the latest published `v0.x` Connector release and the
current `main` branch before the first stable release.

Do not include PersonaStack bearer tokens, Hermes API keys, OpenClaw Gateway
tokens, local paths, or prompt bodies in public issues.

The public repository is source-available for audit. Public visibility is not a
license to run, modify, redistribute, or host the Connector outside the rights
granted in `LICENSE`.
